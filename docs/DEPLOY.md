# Despliegue 0.4

Core y dashboard pertenecen al mismo repositorio y tienen ciclos de vida independientes.

- [FeatherPanel / VPS](DEPLOY_FEATHERPANEL.md): imagen, startup, red, variables, health y actualizaciones.
- [Vercel](DEPLOY_VERCEL.md): Root Directory, workspaces, Bun, proxy y OAuth.
- [Recuperación](RECUPERACION.md): rollback y backups.

Ninguna guía ejecuta automáticamente cambios en producción ni contiene credenciales operativas.
